# Memory Palace Creator 🏰

Chrome의 Gemini Nano API를 활용하여 기억술을 위한 생생한 스토리를 생성하는 AI 도구입니다. 외우고 싶은 내용(날짜, 공식, 어휘 등)을 입력하면, AI가 기억하기 쉬운 "기억의 궁전" 이야기로 변환해줍니다.

## 🌟 주요 기능

- **AI 기반 스토리 생성**: Gemini Nano를 활용한 창의적인 기억술 스토리
- **다양한 테마**: 판타지 성, 우주선, 마법 학교 등 6가지 테마
- **오프라인 지원**: 인터넷 연결 없이도 작동
- **프라이버시 보호**: 모든 데이터는 로컬에서만 처리
- **스토리 관리**: 생성된 스토리 저장, 불러오기, 삭제
- **다크모드**: 눈이 편안한 다크 테마 지원
- **반응형 디자인**: 모바일에서도 완벽하게 작동

## 📋 시스템 요구사항

### 필수 요구사항
- **브라우저**: Chrome 127+ (Chrome Canary 권장)
- **운영체제**: Windows 10/11, macOS 13+, Linux
- **저장공간**: 최소 22GB (Gemini Nano 모델용)
- **메모리**: 4GB+ VRAM 권장

### Chrome 설정
1. Chrome 주소창에 `chrome://flags` 입력
2. 다음 플래그 활성화:
   - `Prompt API for Gemini Nano` → Enabled
   - `Optimization Guide On Device Model` → Enabled (필요시)
3. Chrome 재시작

## 🚀 사용 방법

### 1. 프로젝트 실행
```bash
# 프로젝트 폴더로 이동
cd memory-palace-creator

# 로컬 서버 실행 (Python 3)
python -m http.server 8000

# 또는 Node.js 사용시
npx http-server
```

브라우저에서 `http://localhost:8000` 접속

### 2. 기억의 궁전 만들기

1. **테마 선택**: 원하는 배경 테마 선택 (판타지 성, 우주선 등)
2. **항목 입력**: 기억하고 싶은 내용 추가
   - 카테고리 선택 (날짜, 공식, 어휘, 숫자, 기타)
   - 내용 입력
   - `+ 항목 추가` 버튼으로 여러 항목 추가 가능
3. **스토리 생성**: `기억의 궁전 생성하기` 버튼 클릭
4. **스토리 확인**: AI가 생성한 창의적인 스토리 확인
5. **저장**: 마음에 들면 저장 버튼으로 보관

### 3. 예시 사용법

#### 역사 날짜 외우기
- 항목 1: [날짜] 1492년 - 콜럼버스 아메리카 발견
- 항목 2: [날짜] 1789년 - 프랑스 혁명
- 테마: 시간여행 기계

#### 과학 공식 외우기
- 항목 1: [공식] E=mc² - 질량-에너지 등가원리
- 항목 2: [공식] F=ma - 뉴턴의 운동 법칙
- 테마: 마법 학교

## 🛠️ 기술 스택

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **AI**: Chrome Gemini Nano Prompt API
- **스토리지**: LocalStorage
- **디자인**: 반응형 UI, 다크모드

## 🔧 문제 해결

### API를 사용할 수 없음
- Chrome 버전 확인 (127+ 필요)
- Chrome 플래그 설정 확인
- Chrome Canary 사용 권장

### 모델 다운로드 필요
- 충분한 저장공간 확보 (22GB+)
- 안정적인 인터넷 연결 확인
- 다운로드 완료까지 대기

### 스토리 생성 실패
- 하드웨어 요구사항 확인
- 브라우저 콘솔에서 오류 메시지 확인
- 페이지 새로고침 후 재시도

## 📚 기억술 팁

1. **시각적 이미지**: 생성된 스토리의 시각적 요소에 집중
2. **감정 연결**: 재미있거나 놀라운 부분을 기억
3. **반복 연습**: 스토리를 여러 번 읽고 상상
4. **개인화**: 필요시 스토리 재생성으로 더 맞는 버전 찾기

## 🔐 프라이버시

- 모든 데이터는 브라우저 로컬에서만 처리
- 서버로 전송되는 정보 없음
- 스토리는 브라우저의 LocalStorage에만 저장
