📋 시스템 요구사항

  • Chrome 138+ 브라우저 (Chrome Canary 권장)
  • 운영체제: Windows 10/11, macOS 13+, Linux
  • 하드웨어: 22GB+ 저장공간, 4GB+ VRAM
  • 네트워크: 언어팩 다운로드용 안정적인 연결
  • 참고: 모바일/iOS/Android는 아직 지원되지 않음
⚠️ 실험적 API: Chrome 138+에서 사용 가능하며, chrome://flags에서 관련 설정이 필요할 수 있습니다.
🔒 모델 다운로드: 새로운 언어 모델이 필요한 경우, 언어 선택 시 자동으로 다운로드됩니다.
