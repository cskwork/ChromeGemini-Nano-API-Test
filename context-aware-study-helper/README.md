# Context-Aware Study Helper 📚

Chrome의 Gemini Nano API를 활용하여 브라우저에서 작업하는 내용을 실시간으로 분석하고 학습에 도움이 되는 맞춤형 제안을 제공하는 AI 도우미입니다.

## 🌟 주요 기능

### 🤖 컨텍스트 인식 학습 도움
- **자동 페이지 분석**: 현재 보고 있는 웹페이지 내용을 자동으로 분석
- **맞춤형 제안**: 콘텐츠 유형에 따른 최적화된 학습 도움말 제공
- **실시간 모니터링**: 페이지 변경이나 내용 업데이트를 자동 감지

### 📖 다양한 분석 모드
- **용어 정의**: 중요한 개념과 용어를 자동으로 추출하고 설명
- **참고자료 제안**: 관련 학습 자료와 참고문헌 추천
- **퀴즈 생성**: 학습한 내용을 확인할 수 있는 퀴즈 자동 생성
- **내용 요약**: 긴 텍스트의 핵심 내용을 간단하게 정리
- **코드 설명**: 프로그래밍 코드의 목적과 작동 방식 해설

### 🎯 스마트 컨텍스트 감지
- **Google Docs**: 논문 작성 시 참고문헌 및 용어 정의 제안
- **코딩 사이트**: 코드 설명과 관련 개념 학습 지원
- **교육 콘텐츠**: 내용 요약과 학습 퀴즈 제공
- **연구 논문**: 핵심 용어 정의와 추가 참고자료 추천

### 🎨 사용자 친화적 인터페이스
- **다크모드**: 눈이 편안한 다크 테마 지원
- **반응형 디자인**: 모바일에서도 완벽하게 작동
- **키보드 단축키**: 빠른 분석을 위한 단축키 지원
- **설정 커스터마이징**: 개인 선호도에 맞는 설정 조정

## 📋 시스템 요구사항

### 필수 요구사항
- **브라우저**: Chrome 127+ (Chrome Canary 권장)
- **운영체제**: Windows 10/11, macOS 13+, Linux
- **저장공간**: 최소 22GB (Gemini Nano 모델용)
- **메모리**: 4GB+ VRAM 권장

### Chrome 설정
1. Chrome 주소창에 `chrome://flags` 입력
2. 다음 플래그 활성화:
   - `Prompt API for Gemini Nano` → Enabled
   - `Optimization Guide On Device Model` → Enabled (필요시)
3. Chrome 재시작

## 🚀 사용 방법

### 1. 프로젝트 실행
```bash
# 프로젝트 폴더로 이동
cd context-aware-study-helper

# 로컬 서버 실행 (Python 3)
python -m http.server 8000

# 또는 Node.js 사용시
npx http-server
```

브라우저에서 `http://localhost:8000` 접속

### 2. 자동 학습 도움

#### 📝 Google Docs에서 논문 작성
1. Google Docs에서 논문이나 리포트 작성
2. Study Helper가 자동으로 페이지 감지
3. 주요 용어 정의 및 참고문헌 제안 받기
4. 논리적 구조나 빠진 개념 확인

#### 💻 코딩 튜토리얼 학습
1. 코딩 튜토리얼 사이트 방문
2. 자동으로 코드 분석 모드 활성화
3. 코드 한 줄씩 설명 받기
4. 관련 개념 퀴즈로 이해도 확인

#### 📚 학습 자료 읽기
1. 교육 사이트나 위키피디아 등에서 학습
2. 핵심 내용 자동 요약 제공
3. 중요 용어 정의 확인
4. 추가 학습 자료 추천

### 3. 수동 분석 기능

#### 🔍 현재 페이지 분석
- "현재 페이지 분석하기" 버튼 클릭
- 페이지 내용을 AI가 자동으로 분석
- 컨텍스트에 맞는 학습 도움말 제공

#### 💬 맞춤 질문
- 분석 유형 선택 (용어 정의, 퀴즈 생성 등)
- 특정 텍스트 입력하여 분석
- 원하는 방식의 학습 도움 받기

### 4. 단축키
- `Ctrl + Shift + A`: 현재 페이지 빠른 분석
- `Ctrl + Shift + H`: 도움말 패널 토글

## 🔧 주요 특징

### 🔒 프라이버시 보호
- **로컬 처리**: 모든 AI 분석이 브라우저에서 로컬로 실행

- **효율적 분석**: 필요한 부분만 선택적으로 분석

- **배경 실행**: 사용자 작업을 방해하지 않는 백그라운드 처리

### 🎛️ 커스터마이징
- **분석 주기 조절**: 자동 분석 빈도 설정
- **알림 시간 설정**: 도움말 표시 시간 조정
- **난이도 조절**: 초급/중급/고급 수준별 설명
- **테마 선택**: 라이트/다크 모드 지원

- **Frontend**: HTML5, Tailwind CSS, Vanilla JavaScript
- **AI Engine**: Chrome Gemini Nano Prompt API
- **스토리지**: LocalStorage (브라우저 로컬 저장)
- **아키텍처**: 모듈식 클래스 기반 설계

## 🔧 문제 해결

### API를 사용할 수 없음
- Chrome 버전 확인 (127+ 필요)
- Chrome 플래그 설정 확인
- Chrome Canary 사용 권장
- 브라우저 재시작 후 재시도

### 모델 다운로드 필요
```
상태: downloadable 또는 downloading
```
- 충분한 저장공간 확보 (22GB+)
- 안정적인 인터넷 연결 확인
- 다운로드 완료까지 대기 (최대 30분)
- 백그라운드에서 자동 진행

### 분석 결과가 표시되지 않음
- 페이지에 충분한 텍스트 콘텐츠가 있는지 확인
- API 상태가 'available'인지 확인
- 브라우저 콘솔에서 오류 메시지 확인
- 페이지 새로고침 후 재시도

### 자동 분석이 작동하지 않음
- 설정에서 "자동 분석" 체크박스 확인
- API가 정상적으로 초기화되었는지 확인
- 페이지에 분석할 만한 내용이 있는지 확인

## 📚 사용 팁

### 효과적인 학습을 위한 활용법
1. **단계별 학습**: 용어 정의 → 내용 요약 → 퀴즈 순서로 진행
2. **반복 확인**: 중요한 개념은 여러 번 다른 방식으로 분석
3. **연관 학습**: 참고자료 제안을 활용해 관련 지식 확장
4. **능동적 참여**: 퀴즈나 질문을 통해 수동적 읽기에서 벗어나기

### 맞춤 설정 추천
- **초보자**: 난이도 '쉬움', 알림 시간 '1분'
- **중급자**: 난이도 '보통', 알림 시간 '30초' (기본값)
- **고급자**: 난이도 '어려움', 알림 시간 '15초'
