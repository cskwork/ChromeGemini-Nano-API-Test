📋 시스템 요구사항 및 설정

🚨 window.ai 오류 해결 방법:
  1. Chrome 버전: chrome://version/에서 127+ 확인
  2. 필수 플래그 활성화:
    • chrome://flags/#prompt-api-for-gemini-nano → "Enabled"
    • chrome://flags/#optimization-guide-on-device-model → "Enabled"
  3. Chrome 재시작 후 다시 테스트
  4. Chrome Canary 사용 권장 (최신 기능 지원)
  • Chrome 127+ 브라우저 (Chrome Canary 권장)
  • Windows 10/11 또는 macOS 13+ (Ventura)
  • 22GB+ 저장공간 및 4GB+ VRAM
  • 위의 플래그 설정 필수
