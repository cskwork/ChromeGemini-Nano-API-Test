# 개념 관계 시각화 도구
## Concept Relationship Visualization Tool

Chrome의 Gemini Nano AI를 활용한 고급 학습 도구로, 학습 자료에서 개념 간의 연결고리를 발견하고 역동적인 개념 맵을 생성합니다.

## 🎯 주요 기능

### 📊 AI 기반 개념 분석
- **자동 개념 추출**: 텍스트에서 핵심 개념을 자동으로 식별
- **관계 분석**: 개념 간의 연관성, 인과관계, 계층구조 등을 분석
- **중요도 평가**: 각 개념의 중요도를 1-10점으로 평가

### 🌐 인터랙티브 시각화
- **동적 그래프**: D3.js 기반의 포스-다이렉티드 레이아웃
- **노드 상호작용**: 드래그, 줌, 팬 기능으로 자유로운 탐색
- **관계 표시**: 선의 두께로 관계 강도를 시각적으로 표현
- **카테고리별 색상**: 개념 유형에 따른 색상 구분

### 📚 누적 학습 시스템
- **지식 네트워크 구축**: 여러 세션에 걸쳐 지식을 누적
- **자동 병합**: 새로운 개념과 기존 지식의 스마트 통합
- **데이터 지속성**: 브라우저 로컬 스토리지를 통한 자동 저장

### 🔍 고급 탐색 기능
- **실시간 검색**: 개념 이름, 설명, 카테고리로 검색
- **관계 필터**: 강도별 관계 필터링
- **하이라이트**: 연결된 개념들을 시각적으로 강조

## 📋 시스템 요구사항

### 필수 요구사항
- **Chrome 브라우저**: 127+ 버전 (Chrome Canary 권장)
- **운영체제**: Windows 10/11, macOS 13+, Linux
- **하드웨어**: 4GB+ VRAM, 22GB+ 저장공간
- **네트워크**: 모델 다운로드용 안정적인 연결

### Chrome 설정
1. `chrome://flags` 접속
2. "Prompt API for Gemini Nano" 검색 후 활성화
3. "Optimization Guide On Device Model" 활성화
4. Chrome 재시작

## 📖 사용법

### 1. 기본 사용 흐름
1. **텍스트 입력**: 학습하고자 하는 내용을 텍스트 영역에 입력
2. **분석 실행**: "개념 분석하기" 버튼 클릭
3. **결과 확인**: 생성된 개념 맵에서 관계 탐색
4. **지식 구축**: 추가 자료 분석으로 네트워크 확장

### 2. 고급 기능 활용

#### 개념 검색 및 필터링
- **검색창 활용**: 특정 개념을 찾아 관련 내용 탐색
- **관계 강도 슬라이더**: 약한 관계를 숨기고 핵심 연결만 표시
- **뷰 리셋**: 초기 화면으로 돌아가기

#### 네트워크 관리
- **자동 저장**: 분석 결과는 자동으로 브라우저에 저장
- **네트워크 저장**: JSON 파일로 지식 네트워크 내보내기
- **누적 학습**: 새로운 자료 분석 시 기존 지식과 자동 병합

### 3. 효과적인 학습 팁

#### 최적의 입력 텍스트
- **길이**: 200-2000자 정도의 적절한 분량
- **구조**: 명확한 개념과 설명이 포함된 텍스트
- **예시**: 강의 노트, 교과서 내용, 논문 요약, 기사 등

#### 시각화 활용법
- **노드 크기**: 큰 노드일수록 중요한 개념
- **연결선 두께**: 두꺼운 선일수록 강한 관계
- **색상 구분**: 카테고리별로 다른 색상으로 표시
- **상호작용**: 노드 드래그로 배치 조정, 호버로 상세 정보 확인

## 🔧 기술 사양

### 핵심 기술
- **AI 엔진**: Chrome Gemini Nano Prompt API
- **시각화**: D3.js v7 포스-다이렉티드 그래프
- **UI 프레임워크**: Tailwind CSS
- **데이터 저장**: 브라우저 LocalStorage
- **언어**: Vanilla JavaScript (ES6+)

### API 사용 흐름
```javascript
// 1. API 상태 확인
const status = await LanguageModel.availability();

// 2. 세션 생성
const session = await LanguageModel.create();

// 3. 개념 추출 프롬프트
const concepts = await session.prompt(conceptExtractionPrompt);

// 4. 관계 분석 프롬프트
const relationships = await session.prompt(relationshipAnalysisPrompt);

// 5. 세션 정리
await session.destroy();
```

### 데이터 구조
```javascript
// 개념 객체
{
    id: "unique_concept_id",
    name: "개념 이름",
    description: "개념 설명",
    importance: 1-10,
    category: "카테고리",
    size: 20-40
}

// 관계 객체
{
    source: "source_concept_id",
    target: "target_concept_id",
    type: "관계 유형",
    strength: 1-10,
    description: "관계 설명",
    width: 1-5
}
```

## 🐛 문제 해결

### 일반적인 오류

#### API 사용 불가능
**증상**: "API를 사용할 수 없습니다" 오류
**해결방법**:
1. Chrome 버전 확인 (127+ 필요)
2. `chrome://flags`에서 Gemini Nano 플래그 활성화
3. Chrome 재시작 후 재시도
4. Chrome Canary 사용 권장

#### 모델 다운로드 필요
**증상**: "모델 다운로드가 필요합니다" 메시지
**해결방법**:
1. 안정적인 인터넷 연결 확인
2. 충분한 저장공간 확보 (22GB+)
3. 다운로드 완료까지 대기

#### 세션 생성 실패
**증상**: "세션 생성에 실패했습니다" 오류
**해결방법**:
1. 하드웨어 요구사항 확인 (4GB+ VRAM)
2. 다른 AI 세션들 종료
3. 브라우저 재시작 후 재시도

### 성능 최적화

#### 대용량 텍스트 처리
- 텍스트를 2000자 이하로 분할하여 분석
- 핵심 내용만 추출하여 입력
- 단계적으로 분석하여 네트워크 구축

#### 시각화 성능
- 개념 수가 50개를 초과하면 필터링 활용
- 약한 관계(강도 3 이하) 숨기기
- 정기적으로 뷰 리셋으로 성능 최적화

## 📊 사용 예시

### 예시 1: 머신러닝 개념 학습
**입력 텍스트**:
```
머신러닝은 인공지능의 한 분야로, 컴퓨터가 명시적인 프로그래밍 없이 데이터로부터 학습하는 능력입니다. 
지도학습은 레이블이 있는 데이터로 훈련하며, 비지도학습은 레이블 없는 데이터에서 패턴을 찾습니다. 
강화학습은 환경과 상호작용하며 보상을 통해 학습합니다.
```

**예상 결과**:
- 개념: 머신러닝, 인공지능, 지도학습, 비지도학습, 강화학습, 데이터, 패턴
- 관계: 머신러닝 ← 포함 ← 인공지능, 지도학습 ← 유형 ← 머신러닝

### 예시 2: 역사 사건 분석
**입력 텍스트**:
```
프랑스 혁명은 1789년에 시작되어 절대왕정을 무너뜨리고 공화정을 수립했습니다. 
경제적 위기와 사회적 불평등이 주요 원인이었으며, 계몽사상이 사상적 배경을 제공했습니다.
```

**예상 결과**:
- 개념: 프랑스혁명, 절대왕정, 공화정, 경제위기, 사회불평등, 계몽사상
- 관계: 경제위기 → 원인 → 프랑스혁명, 프랑스혁명 → 결과 → 공화정

## 📝 기술 용어 설명

### AI 및 머신러닝 용어
- **Gemini Nano**: Google이 개발한 경량화된 AI 언어 모델로, 브라우저에서 직접 실행 가능
- **Prompt API**: 브라우저에서 AI 모델과 상호작용할 수 있게 해주는 웹 API
- **세션(Session)**: AI 모델과의 대화를 관리하는 연결 단위

### 시각화 용어
- **D3.js**: 데이터 기반 문서(Data-Driven Documents)를 만들기 위한 JavaScript 라이브러리
- **포스-다이렉티드 그래프**: 물리 시뮬레이션을 사용하여 노드를 자동으로 배치하는 그래프 레이아웃
- **노드(Node)**: 그래프에서 개념을 나타내는 점
- **엣지/링크(Edge/Link)**: 그래프에서 개념 간의 관계를 나타내는 선

### 웹 기술 용어
- **Tailwind CSS**: 유틸리티 우선(Utility-First) CSS 프레임워크
- **LocalStorage**: 브라우저에 데이터를 저장할 수 있는 웹 스토리지 기술
- **JSON**: JavaScript Object Notation의 줄임말로, 데이터 교환 형식

### 학습 과학 용어
- **개념 맵**: 개념들과 그들 사이의 관계를 시각적으로 표현한 도구
- **지식 네트워크**: 서로 연결된 개념들의 전체적인 구조
- **누적 학습**: 새로운 정보를 기존 지식과 연결하여 점진적으로 학습하는 방법
